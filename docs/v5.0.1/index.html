Asynchronous text to speech

Queues a job that generates the MP3 and uploads it to the presigned URL returned by genUploadUrl. Progress goes to statusCallbackUrl. A 202 means queued, not done.

header Parameters
Authorization
string

Passed through to the callbacks. Optional.

Request Body schema: application/json
required
genUploadUrl
required
string\S

Called once per attempt to get a presigned PUT URL. Replies with 200 and {"uploadUrl": "..."}.

statusCallbackUrl
required
string\S

Receives the progress and status reports.

text
required
string\S

The text to synthesize.
